Robust Compute-in-Memory for Edge Healthcare

ESE 5760 · Semiconductor Memory · Spring 2026

Designed and analysed a robust compute-in-memory (CiM) architecture targeting edge healthcare inference workloads as part of the ESE 5760 (Advanced VLSI) course at the University of Pennsylvania. The work connects hardware-aware neural-network training with analog crossbar nonidealities and technology-level energy–delay tradeoffs.

Architecture

Built a hardware-aware training framework in PyTorch using a 4-bit straight-through estimator to map a 682k-MAC convolutional neural network onto 2T2R differential crossbars. Modeled OxRAM random-telegraph noise, PCM resistance drift, and array RC parasitics, with NeuroSim supporting the hardware evaluation.

Key Results

  • Hardware-aware inference — 4-bit quantization and differential-crossbar mapping.
  • Robustness — limited Macro-F1 degradation to below 3% in the evaluated nonideality study.
  • Technology comparison — evaluated device-level nonidealities alongside energy–delay tradeoffs.
