PHOTOGRAPHY AND MEDIA
Add a JPEG display copy under assets/gallery/ and an entry in photos.json:
  {"file":"photo.jpeg", "caption":"Descriptive caption"}
Use exact filename case and valid JSON (no trailing comma on the last entry).
Run with Python + Pillow:
  python3 scripts/optimize-media.py
This preserves private originals, corrects orientation, resizes to <=1600 px,
removes metadata, compresses the JPEG, and verifies EXIF is empty. It does not
watermark photographs. A watermark placement requires a separately reviewed sample.
The gallery is display-only: figures, no clickable images or lightbox, and no
image dragging. This is a deterrent, not a guarantee against saving/screenshots.
Do not block right-click as a substitute for actual privacy protection.
